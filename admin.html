Le skill di Claude Code create per Efuture Games. Si usano in una sessione di Claude Code aperta sul repository efuture_games: scrivi il comando (es. /efuture-games-qr) oppure chiedilo a parole.

I 5 QR dell'evento: il QR dell'app (installazione) e i 4 QR di sblocco degli stand. Si stampano tutti su un foglio A4, in bianco e nero, con le linee tratteggiate per ritagliarli.

Il database online non è configurato in config.js: il pannello admin funziona solo con Supabase.

Nuovo utente
